# 💱 Currency Converter

A simple and user-friendly **Currency Converter Web Application** built using **HTML, CSS, and JavaScript**. It allows users to enter an amount, select two currencies, and get the converted amount using exchange-rate data from an API.

## ✨ Features

- Convert one currency into another
- Supports multiple currencies
- USD selected as the default From currency
- INR selected as the default To currency
- Automatically updates currency flags
- Fetches exchange rates using an API
- Calculates the converted amount dynamically
- Validates the entered amount
- Simple and clean user interface
- Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Currency API
- FlagsAPI
- Font Awesome
